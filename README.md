# Музыкальный плеер на двусвязном списке

Практическая работа №1 по курсу «Алгоритмы и структуры данных».
Это настольный аудиоплеер. Плейлисты в нём хранятся в собственной реализации
кольцевого двусвязного списка.

## Возможности

- Создание и удаление плейлистов.
- Добавление аудиофайлов (`mp3`, `wav`, `ogg`, `flac`, `m4a`, `aac`), удаление композиций.
- Изменение порядка композиций: кнопками «выше/ниже» или перетаскиванием мышью.
- Воспроизведение, пауза, переход к следующей или предыдущей композиции.
  После последней композиции плейлист начинается сначала.
- Перемотка ползунком и регулировка громкости.

### Горячие клавиши

| Клавиши                 | Действие                        |
|-------------------------|---------------------------------|
| `Space`                 | Играть / пауза                  |
| `Ctrl+→` / `Ctrl+←`     | Следующая / предыдущая          |
| `Ctrl+N` (`⌘N` в macOS) | Новый плейлист                  |
| `Ctrl+O` (`⌘O` в macOS) | Добавить композиции             |
| `Delete`                | Удалить выбранную композицию    |

## Установка и запуск

Нужен Python 3.10 или новее.

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## Структура проекта

```
first_practical/
├── main.py                     # точка входа
├── models/
│   ├── linked_list.py          # LinkedListItem и LinkedList: кольцевой двусвязный список
│   ├── playlist.py             # PlayList: список с текущим треком, next/previous
│   └── composition.py          # Composition: путь к файлу и название
├── services/
│   └── player_controller.py    # связывает окно, плейлисты и pygame.mixer
├── ui/
│   └── main_window.py          # интерфейс на PySide6
└── test/
    ├── linked_list.py          # заглушка модуля для тестов
    └── test_linked_list.py     # тесты связного списка
```

Архитектура:

- `ui` отвечает только за отображение и испускает Qt-сигналы.
- `PlayerController` принимает эти сигналы, изменяет модели и воспроизводит
  звук через `pygame.mixer`.
- `models` не зависят ни от интерфейса, ни от звука.

## Связный список

`LinkedList` — кольцевой двусвязный список: у последнего узла `next_item`
указывает на первый, у первого `previous_item` указывает на последний.

| Операция                                | Сложность |
|-----------------------------------------|-----------|
| `append_left`, `append_right`, `last()` | O(1)      |
| `insert`, `remove`, `in`                | O(n)      |
| `list[i]` (обход с ближайшего конца)    | O(n/2)    |
| `len()`                                 | O(1)      |

Поддерживаются `for`, `reversed()`, отрицательные индексы и перестановка
`move(src, dst)`.

## Проверка кода

```bash

cd test && python -m unittest
```

Тесты импортируют `test/linked_list.py`. Чтобы проверить собственную
реализацию, замените эту заглушку на `models/linked_list.py`.
